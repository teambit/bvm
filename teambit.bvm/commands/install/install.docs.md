An install command for the bvm CLI tool

With `--next` (alias `--bitx`), installs bitx, the next Bit CLI, as the command named by `BITX_LINK` (default `bit`). Set `BITX_LINK` to `bitx` to keep it side by side with Bit.
See `docs/bitx.md` in the bvm repository.
